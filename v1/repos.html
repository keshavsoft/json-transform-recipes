A breakdown of the zero-dependency, single-responsibility micro-engines powering modern XML-to-JSON cleaning, data projection, key normalization, contract reshaping, and DOM table rendering.

⚡ select-json-by-json
Step 1: Projection

High-performance, zero-dependency JSON projection engine. Traverses bulky nested structures and arrays, pruning away every field not explicitly specified in a declarative projection specification object (true = keep).

Mental Model: Input data is the source of truth. The engine mirrors the original data shape, retaining only requested properties without mutating the source tree.
selectJson(rawData, { INVOICE_NUMBER: true, DATE: true, ALL_INVENTORY_ENTRIES_LIST: { ITEM_NAME: true, TOTAL_AMOUNT: true } });

🏷️ rename-json-keys
Step 2: Normalization

Recursively normalizes property names across deeply nested objects and array collections. Converts uppercase, legacy, or dot-notated XML keys into clean, developer-friendly camelCase property names.

Mental Model: Input data remains the source of truth for values and hierarchy. The mapping dictionary provides substitution rules with support for scoped $as mappings.
renameJsonKeys(projectedData, { INVOICE_NUMBER: "invoiceNo", DATE: "date", ALL_INVENTORY_ENTRIES_LIST: "items", ITEM_NAME: "name", TOTAL_AMOUNT: "amount" });
📂 GitHub Repo 🏷️ Playground & Docs
🗺️ map-json-by-json
Step 3: Contract Mapping

Template-driven declarative JSON transformation engine. Defines the exact target schema required by downstream consumers, pulling source values via dot-notation, static values, and child array mapping.

Mental Model: Target template is the source of truth. The engine instantiates the contract template and populates it using $from array extractors and dot paths.
mapJson({ invoice: "INVOICE_NUMBER", date: "TRANSACTION_DATE", lineItems: { $from: "ALL_INVENTORY_ENTRIES_LIST", product: "ITEM_NAME", total: "TOTAL_AMOUNT" } }, rawData);
📂 GitHub Repo 🗺️ Playground & Docs
📊 json-to-tag-table
Step 4: Table UI

Visual web table generator built for hierarchical and nested datasets. Inspects scalar columns and automatically converts deep sub-arrays (e.g. inventory allocations) into interactive drilldown triggers.

Mental Model: Structured table representation. Transforms flat or deep records into responsive HTML tables with modal drilldowns and custom skinning support.
const table = new Table({ theme: "default", data: cleanJson }); table.methods.render({ targetHtmlId: "tableContainer" });
📂 GitHub Repo 📊 Table Playground
🧩 json-to-tag
Compiler Engine

Zero-dependency JSON-to-DOM compiler and specification validator. Compiles serializable JSON schema specs into live native HTML DOM elements based on a strict catalog schema (tags.json).

Mental Model: Strict catalog enforcement. Ensures attribute safety, permitted nesting rules, and valid tag hierarchies before rendering into the DOM.
jsonToTag({ tag: "div", attributes: { class: "card p-3" }, children: [ { tag: "h4", text: "Dashboard Overview" } ] });
