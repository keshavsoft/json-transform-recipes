json-to-tag-table

Declarative HTML table renderer for nested JSON records. Turns complex hierarchical datasets into interactive web tables with child-collection expansion.

Structured JSON Data Input
Live Rendered Table View

Quick API Guide

Load the browser bundle directly from jsDelivr CDN:

<script src="https://cdn.jsdelivr.net/gh/keshavsoft/json-to-tag-table@main/docs/dist/v6/min.js"></script>

Instantiate and render into any target container:

const table = new globalThis.ks.jsonToTagTable.Table({ theme: "default", data: myTransformedData }); table.methods.render({ targetHtmlId: "myContainerId", inSkeletonType: "tableSimple" });
