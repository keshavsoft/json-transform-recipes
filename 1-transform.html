Core Engine Capabilities

    

      node-json-transformer replaces disjointed multi-step pipelines with a unified specification, executing projection, renaming, and nesting in one clean pass.
    


    

      

        
🎯

        
Field Selection

        

          Discards unneeded upstream metadata and noisy keys. Only declared contract properties are projected into the output JSON.
        

        
{ "invoiceNo": "INVOICE_NUMBER" }

      


      

        
🏷️

        
Property Normalization

        

          Renames legacy SCREAMING_SNAKE_CASE or ERP keys into clean camelCase, PascalCase, or custom internal schema names.
        

        
{ "customer": "CUSTOMER_NAME" }

      


      

        
🌳

        
Hierarchical Sub-Arrays

        

          Iterates deep nested arrays (e.g. line items, batch allocations, tax splits) and transforms each child record declaratively.
        

        
"items": [{ "list": "ENTRIES", "item": {...} }]

      


      

        
⚡

        
XML & Dot-Notation Keys

        

          Safely traverses nested objects and properties converted from XML/Tally structures using standard dot-delimited path expressions.
        

        
{ "qty": "BATCH.ALLOCATION.QTY" }

      

    


    
    

      

        

          
Mental Model & Architecture

          

            Instead of executing multiple separate steps across different packages, node-json-transformer accepts the source payload and an output contract description.
          

          

            The transformation map acts as a template: the output JSON mirrors the shape of the recipe, pulling and casting values from the source payload in real time with zero intermediate allocations.
          

          

            
              Pure Declarative
            
            
              Zero Dependencies
            
            
              Browser & Node.js Compatible
            
          

        


        

          

// 1. Install via npm
npm install node-json-transformer

// 2. Import & Execute
const { transform } = require("node-json-transformer");

const sourceData = {
  "INVOICE_NUMBER": 1001,
  "CUSTOMER_NAME": "Alpha Corp"
};

const recipe = {
  "mapping": {
    "item": {
      "invoiceNo": "INVOICE_NUMBER",
      "client": "CUSTOMER_NAME"
    }
  }
};

const cleanContract = transform(sourceData, recipe);
// Output: { invoiceNo: 1001, client: "Alpha Corp" }
